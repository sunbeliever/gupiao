# 科技观察 Android 数据分析应用

用户已确认制作，平台改为 APK；覆盖中国科技 A 股与科技 ETF、2025/2026 回测、联网行情/新闻和持续训练。核心是展示参数与分析依据。

Android 原生 Java 容器加载本地 HTML/JS；HTTPS 数据桥限制来源，缓存私有存储。初始模型和真实历史样本随 APK 提供。API 23+，目标 API 35，无账户、无交易权限。

研究池含芯片、算力、软件、通信、科创 ETF。报价每30秒刷新，来源时间可见；后台受 Android 调度约束采集新闻/报价，重新打开应用同步日线及训练。

展示价格、涨跌、成交量、金额、换手、PE/PB、MA5/20/60、RSI14、5/20/60日动量、波动、回撤；ETF PE/PB 显示不适用。新闻链接、来源和日期可见，情绪为透明关键词观察，不混作已验证的预测因子。

初始模型采用标准化岭回归预测20个交易日收益，因素贡献可追溯。只从完整日线产生信号，训练仅含标签已实现的样本。2024验证选择正则，2025冻结检验，2026展示截至已完成日期的滚动检验；禁止训练读取对应测试未来数据。当前研究池存在幸存者偏差，日线模拟不宣称可实际成交。报价与财务指标不加入历史预测。

更新采用固定时间窗口比较候选与现有模型；仅当样本数和误差改善满足门槛才升级，记录版本/训练截止日/指标。更新不保证盈利或持续改善。

回测显示误差、方向命中、同池排名分组表现、模拟净值、费用、回撤和基准。模拟使用次日开盘，按20日区间、保守过滤异常/疑似涨跌停/停牌；保留原始及后复权数据，不用最新报价覆盖日线。

检查包括因子手算、未来扰动不改变历史预测、标签purge、解析缺失/非法值、离线缓存、安全来源限制、APK签名、手机尺寸界面和真实数据端到端训练。
