`independent-market-feed.js` is data-only. The fixed feed ID/root is `independent-native-20261102-b` under D:/techno/validation/market-feed. It verifies and copies the original17 frozen runtime files, two native C# sources and executable into a separate source/cache/response namespace. It never calls account start/advance/recover, imports original wallet data, writes original caches, or starts a scheduler. Initialization is small immutable configuration/copying only; root must execute it from the final main/release bytes so the producer self SHA and dependency SHA match the published files.

API: `initialize()` -> `{manifest,manifestHash}`; `readManifest()` same; `open()` -> `{manifestHash,capture:async(),close()}`; `readCommitted(now=Date.now())` -> `{available,reason,input,record,...}`. `capture()` commits before returning. Larger future timestamps, stale/missing inputs or incomplete instruments remain unavailable. No clock is modified, no future tolerance is widened, and no old observation is relabeled. Original raw input is retained separately from the new observationAt.
