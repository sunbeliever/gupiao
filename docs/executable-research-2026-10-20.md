# 连续账务历史研究：事前固定比较

2026-10-20新增研究工具，投资优势仍未验证。用户授权继续测试优化，仅模拟，不接券商、不购买服务、不增加实际资金。这份协议在本轮首次计算收益前保存。

## 固定问题与样本

比较11因子岭回归正则参数1和10，在相同可执行账务与费用下有无稳定差异。另设事前指定科创50ETF、固定三ETF等权两个简单对照。固定三只为588000、512760、515070，不从后续收益中选择。

仅使用已有`full-capital-optimization/daily-prices.json`的六ETF原始与后复权日线。训练数据先截到2024-12-31，20日收益区间终点不得越过该日；之后权重冻结。研究账户2025-01-02开始，连续到2026-09-30，不按年重置、不逐轮抹去亏损；年度分项是同一账户权益的分解。这两个年份此前已经查看过，不能称新盲测。此处重新拟合的六ETF模型不是EXE部署的19只池模型。

每条研究路径独立以1万元开始，最多3只；原始本金、费用版本、最大可投资额和主题约束固定，不注入资金，也不扩大名义1万元风险上限。全部路径使用`Paper.startAuto/stepAuto/replay`，每个输入保存哈希、逐笔订单及状态哈希，增量与批量回放须逐笔及最终哈希一致。主引擎原有strategy_id仍是引擎族标签；结果另存`researchIdentity`明确绑定真实选择器、模型、数据及规则，不冒充当前EXE业绩。

## 时序、费用与退出

- 只在09:30观察原始开盘价；预测只看前一完整交易日。当天收盘、高低、成交量不参与开盘成交资格。开盘盘口、停牌档案未覆盖，成交始终是假设。
- 15:00收盘价到16:00仅作估值，不伪造14:56可成交价。日内止损触发未知，持仓风险最早在下一个已观察合法开盘处理。
- 共用现有20交易日到期、8%风险退出、T+1、整手、双边佣金最低5元及0.1%滑点。拒单/缺价/到期卖不出保留持仓，期末不强平、不转可用现金。
- 简单对照以明确的固定优先级信号调用相同账务；优先级数值**不是收益预测**。它们也受20日到期和8%退出约束，到后续合法开盘重新配置，因此不是永久买入持有。软件原有只持有一轮20日的内置对照仍保留在账本中，但不拿来冒充长期等暴露基准。
- 已核实的拆分/分红共用原账务。原价与复权价的隔夜比率异常若没有已核实事件，保留警告，阻止投资能力结论。当前名单有幸存者偏差。

## 不以某次赚钱结束

固定四条路径全部运行一次，保留亏损、报错、claim和未完成记录；不因某条亏损修改参数、重开、换时间窗。先看净收益、观测回撤、换手、费用、暴露、未退出风险与逐笔一致性。已平仓胜率单列，不等于20日预测正确率；重叠交易不当独立样本。

本轮没有自动部署资格，即使历史盈利。2026-10-20 11:00已冻结的真实前瞻账户保持原模型/规则/费用/本金，由原驱动继续；研究不写它的冻结目录，不删除采集失败或亏损。需要修复原驱动时保留原实验，新版另建未来实验；不将修复前后结果拼接成同一版本。

后续每日收盘按新数据检查质量及账户；仅有新成熟标签或明确缺陷才开展有界修复/训练，每轮最多两个预登记模型，不反复调到某个窗口赚钱。先完成同输入、逐笔一致性和离线正确性，再另立未来比较。70%盈利机会和10%—20%年回报仍是未验证目标，不把模型分数显示为概率。

## 使用

在当前权威工作树中运行：

```powershell
node --test tests/executable-research.test.js
node scripts/executable-research.js --declare --id shared-account-research-20261020-a --prices D:/techno/validation/full-capital-optimization/daily-prices.json
node scripts/executable-research.js --run --id shared-account-research-20261020-a
```

声明保存源、数据、资金和费用指纹；`--run`有永久claim，重复运行拒绝。输出在`validation/executable-research/ID`；GitHub发布另存固定证据快照，原账户不受影响。此工具不改变Windows EXE、UI或部署权重。
