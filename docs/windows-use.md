# 科技观察 Windows 版

## 打开
双击 `dist/科技观察-全额资金研究版.exe`（1.5.1版）。这是独立的64位Windows桌面程序，不需要安装Python或启动开发环境。先关闭旧窗口再打开新版；本机旧持仓与历史数据会保留。

按用户最新澄清，新模拟将1万元作为全部可投资本金，按实际入选1、2或3只分配，不再用原500元单只上限。整手和费用会留下余款；无合格信号则等待，现金不计预测成功。旧持仓仍按当时资金规则显示，不能回改成新收益。

目标是20个交易日扣费后盈利机会约70%、总账户年收益10%至20%；当前未证明达到。模型页新增全额资金历史检验及失败的概率校准记录。六只ETF趋势候选的2024/2025/2026至9月历史收益约22.48%/29.29%/18.99%，但单笔盈利比例约50%至63%、最大回撤约19%至20%，不是未来承诺，也不是当前19只池部署模型的实盘业绩。旧500元单笔研究折叠保留。

1.5修正模拟账本的已核实ETF拆分与分红：拆分增加份额并调整单位成本，保留原始买价；分红先记应收，在发放日进入可用现金。事件表只覆盖核对过的六只ETF历史至2026-09-30，新事件仍需核查，不能当完整券商账本。

第一次打开会把自带界面和微软WebView2组件释放到 `%LOCALAPPDATA%\TechScopeDesktop`，初始数据已内置。电脑需有微软WebView2运行时；当前制作和验证的电脑已有该组件。

再次双击会切回已有窗口，避免同时打开多个实例争写缓存。

## 怎么看
- **观察**：19只科技A股/科技ETF，比较板块走势、行情与20个交易日收益估计；可搜索、筛选、排序。推荐状态明确显示“暂不发出实盘买入推荐”，因为当前模型尚无稳定优势证明。
- **详情**：股票价格、成交量/额、换手、PE/PB、K线与MA/RSI/动量/波动/回撤等参数，查看因子贡献与参考区间。选定股票可读最近公司公告标题、来源和原文；可复制证券代码、打开官网行情或东方财富官方下载页。未绑定证券账户。
- **资讯**：联网读取科技新闻标题、来源、时间，点开新闻使用系统浏览器。
- **回测**：2025冻结检验、2026逐月滚动检验；参数沿用2024验证选择，同时比较零收益、始终上涨和训练均值这些简单方法，显示实际误差和模拟风险。
- **模型**：查看本机预测日记与训练截止日，重新训练并验证候选；验证未改善就保留现有模型。模型升级不等于实盘有效。

开启“自动同步与验证”后，前台每30秒更新行情。最小化时由宿主每5分钟采集报价和科技新闻。关闭窗口会停止更新，不创建开机自启或后台系统服务。

行情、日线和模型存储在本机用户目录；替换EXE不会主动清除它们。来源连接失败时保留已有数据并显示缓存状态；没有数据的指标显示缺失。

1.5.1修复主日线接口返回成功但日期过旧时未尝试备用来源的问题，旧缓存会重新核验。2026-10-19独立数据检查19只均到当天，但Windows原生备用连接仍不稳定，实际日期须以每只显示为准，不能认为全池均已最新；原收盘后复核失败保留，未伪造新预测或收益。

## 分析范围
初始模型采用价格与成交量技术因子。新闻会展示并积累观察记录，尚未作为历史预测训练因子。研究池存在幸存者偏差，回测属于日线区间模拟，不能代表实盘成交或未来收益。

没有训练或接入大语言模型。当前嵌入数据检验中，2026截至9月30日方向命中42.93%，始终预测上涨42.89%；模型收益平均误差11.25个百分点，零收益10.68个百分点、训练均值11.13个百分点。现有结果不支持直接依排名买入。此次更新提升可核查性，没有证明预测准确率提高。

本次还在开发机训练了非线性梯度提升分类候选，使用时间隔离的拟合、概率校准和年度冻结检验。候选没有稳定胜过简单先验；2026分数≥0.70仅触发5个重叠标签，不能证明70%长期盈利。因此未替换EXE中的现有模型，研究结果会显示在模拟页，不能把输出分数当已证实的成功概率。

本机预测日记保存首次实际发布时间、模型快照和11个因子输入，同标的/信号日/周期不覆盖。新日线同步后，按共享已观察交易日历从次日开盘至20个交易日后开盘评分；迟于入场开盘发布的记录排除，缺失入场/到期价格时等待补数。记录不是实际成交，不是独立防篡改认证，不把回测填成前瞻成绩。最多索引最近24个月，软件关闭时不记录。观察多日、多月且考虑风险后才能判断是否有价值；当前不自动认定“可实盘”。

免费公开接口可能延迟、限流或中断，无法保证即时捕捉所有新闻。公司公告约30分钟复用缓存，仅展示所选公司的最新有限结果；基金公告尚未接入。公告、新闻和当前估值仍未输入预测。

## 模拟投资
1.4新增“软件全自动模拟30分钟”。资金设置沿用下方输入；软件冻结当时的模型、20日预测与开盘参考，每次新报价重新检查现有买入条件。达到冻结模型的20日估计目标价时请求撤出，受T+1限制则记录未执行，不假装当天平仓；半小时结束只记录账面资产。每个标的在一轮内最多买入一次，最多3只，不中途按结果换参数。自动模式额外计股票卖出印花税0.05%及双边过户费0.001%，ETF二级买卖不收这两项；佣金和滑点仍是假设，无盘口成交验证。需要连续剩余至少半小时的交易时段，前台联网运行；超过90秒采样中断会标为不完整，不能作为完成测试。

模型页还会显示历史随机24个半小时窗口（实际可用数量以结果为准）。它按真实5分钟收盘快照重放，区别于实时30秒采样；只使用窗口前已完成日线，固定种子与规则，缺失未来行情保留未完成。各窗口是独立1万元账户，不复利合并；现金不计成功。新闻未进入模型，没有事后补写新闻原因。新增撤出规则本身仍待验证，不能凭半小时盈利认定20日预测有效。

观察页点“1万元全额资金模拟与测试结果”，或在“模型”页点“联网更新并开始模型模拟”。默认虚拟投资本金1万元，按实际入选1至3只分配全部可用资金，留整手/费用余款；模拟单边最低佣金5元。自动模式后续入场按剩余现金和空位分配，不重复使用原1万元额度。总本金和最低佣金可填写，单只额度由软件计算；须按实际券商约定核查，不能为让结果好看而假设免佣。

程序先同步完整研究池日线与新报价，再用当前模型筛选普通股票和科技ETF。新手模式默认未开通科创板/创业板个股权限，排除这些股票；按整手、单只额度及估计扣费后收益排序，选择最多3只。无标的满足条件时，允许建立全部现金的模拟账户，并保存完整排除原因。这属于不交易决定，不是预测成功，也不能因为没有亏钱就宣称70%胜率。数据同步失败不会冒充策略空仓。

1.3.1修正了估计起点：先按当前交易日开盘价将“信号后开盘至20日后”的收益估计换算到盘中模拟买入价，再比较双边费用。缺少开盘参考不做该比较；这不是重新训练的盘中预测。制作期间初始1.3试验保留原始规则和发现的问题，修正版另行建立实际观察，不回写旧成绩。

也可在个股详情“模拟买入此标的”做手动指定试验，仍受小额限制，结果单独标为手动；自动选择与手动结果不混合。每次新建前归档旧记录（最近10组）。新设置仅用于新建模拟，不回改旧模拟本金、费用和持仓。1.2版留下的10万元持仓继续按其原有假设估值。

估算采用100股整手（遗留研究可含至少200股的科创板）；模拟买价在来源最新价之上加0.1%滑点，买入佣金近似0.03%与设定最低额取较大值。小额筛选同时估算双边佣金与滑点，成本门槛尚未含股票印花税和过户费，因此实际可能更高。对照账户用相同费用/滑点假设满仓买入科创50ETF，另有0收益现金对照；研究组合现金比例可能高，不能直接将收益差解释为预测优势。仅按报价做假设买入，不能证明实际订单能够成交；未实现收益不包含未来卖出费用，A股日内不模拟卖出。模型的20日收益目标不同于盘中模拟买入，一小时盈亏不计为20日预测准确率。

观察页与模型页新增“第一次投资”说明，解释股票/ETF、100股或100份、交易权限、T+1、佣金、PE/PB、MA/RSI、回撤与胜率。1万元总预算并不表示必须全部投入；科技ETF之间可能高度相关，不等于全面分散。

开启自动同步并保持软件前台可见，每30秒按已获得的新源报价估值，迟到或缺失价格保留最后源时间；关闭软件后停止。模型页展示冻结持仓、假设买价、股数、余额和源时间，可到官网行情核对。

2023固定抽样8轮记录在模型页展开查看，决策仅使用各信号日之前数据、预先固定随机种子和正则参数；亏损轮次全部保留。当前实验不支持直接实盘投资。

## 验证
Windows版已从只包含EXE的独立中文路径实际启动，验证原生数据桥、中文缓存、五页、ETF筛选、参数明细、冻结2025回测重跑一致及2026回测；实际行情与新闻获取结果见 `validation/desktop/launch-result.json`。

## 运行组件
如果在其他电脑提示缺少WebView2，可从[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装运行时。Windows版采用[微软WebView2宿主接口](https://learn.microsoft.com/en-us/microsoft-edge/webview2/how-to/hostobject)，依赖的许可证与NOTICE随EXE内置。
