# 自主研发路线图（持续沿用）
授权：2026-10-23用户总指令。现有冻结实验、损益、claim与模型均不改变。阶段验收采用工程、研究、收益、风险、易用性五条独立证据。

## 设计与取舍
采用现有Node运行时和SQLite持久队列，Windows当前用户定时任务每5分钟唤醒一次。避免引入网络队列或大模型服务。持久任务独立于聊天；系统关机/用户未登录时不能执行，恢复后按任务状态继续。只执行代码中明确列出的处理器，不从队列执行任意Shell。模型注册仅表示候选存在，自动晋级必须有预先门槛和完整独立未来证据，当前一律不满足。

## 本轮文件边界
scripts/autonomous-research.js：SQLite存储、任务与实验处理器、只读摘要。
scripts/run-autonomous-research.js：有边界任务执行、资源检查与报告。
scripts/serve-research-view.js及research-account-view.js：只读接入研发区，不改变金融计算。
tests/autonomous-research.test.js：事务/重复/崩溃恢复/错误保留/病例归因与转义集成。
D:/techno/validation/autonomous-research：稳定数据库、不可变输入与结果、调度证据。冻结账户只读。

## 晋级与资源
每轮最长25分钟，任务超时保留失败。训练不得挤占交易时段采集，内存不足记录blocked。已看2023—2026仅探索，病例对照不是独立样本。收益、回撤、夏普、Calmar、换手、成本、基准、样本外稳定性、市场状态缺一不可；缺失用null并阻止晋级。未实现自动代码生成的研究留待开发，不能标成功。
