# 现有系统能力与缺口审查

审查日期：2026-10-23。本文基于实际源码、已保存模型与证据；未重新训练、未重跑历史实验，未修改任何运行账户或冻结资料。它是能力事实审查，不是投资建议或模型晋级结论。

## 1. 已实现算法与输入

权威实现为 `assets/analysis.js`：`vector`（75—81行）、`records`（104—116行）、`fit`（136—165行）、`train`（167—170行）、`predict`（190—219行）。

算法是标准化岭回归，不是大语言模型、深度神经网络或联网自主选股。训练先在训练样本上计算均值/标准差，再求解带 alpha × 样本数正则项的线性系统；预测是截距与11项标准化因子贡献之和。已运行模型均为 alpha=1、20交易日周期。

固定11因子为：MA5/20/60价格偏离、RSI14、5/20/60日动量、20日波动率、对数成交量比、60日回撤、ATR14除以价格。每个信号至少需要61根有效完整日线。没有把完整财报、新闻语义、盘口、订单队列、宏观状态或LLM分析接入这11维收益预测。

标签是信号次日开盘到其后20交易日开盘的后复权收益，完整标签终点不得超过训练截止。它不是扣费盈利标签或盈利概率分类。交易费用与滑点由Paper筛选和连续账务另外处理。

## 3. 数据与信号如何产生

`assets/market.js` 的 `history`（49—62行）默认取后复权日线；腾讯为主、东方财富为备用，保存来源、接收/获取时间、截止日、陈旧标记与错误。只接受应已完成交易日之前的日线。`validateHistoryPool`统一核对研究池完整性；缓存/缺价不能当作新鲜成交证据。

日内信号由本机 `Analysis.predict`产生。软件页面在 `assets/ui.js:73`调用；配对账户由 `scripts/paired-forward-core.js` 的 `predictions`及`advance`调用，共同日线hash变化且历史健康时重算预测，权重保持冻结。固定三ETF对照使用显式选择优先级，并不是另一套收益预测。当前信号不是助手阅读新闻后逐笔临时决定。

行情更新、信号重算、训练与部署是四个不同动作。`assets/ui.js`的`trainModel`（360—375行）只保存 `model.researchCandidate`和比较信息，明确不自动替换当前运行模型。原账户冻结来源和资金保持独立。

## 4. 10月22日止损同刻重买的原因

`assets/paper-account.js:127`先调用`exitPositions`，128行紧接着调用`entries`；卖出后资金和空位立即可用于同一输入的筛选。`entries`（69—85行）只排除仍持有的标的及已经买过的“标的:信号日”，没有当日止损排除或冷静期。旧仓使用较早的信号键，下一交易日的新信号可以再次入选。

因此10/22通信ETF515880于10:07:14.746风险退出7700份、实现亏损179.7619元后，同批输入又买8400份；新买价0.513513元，新仓最早10/23可卖、到期11/19。份额变化来自剩余资金/仓位约束下重新整手分配。止损是冻结持仓退出条件，不等于模型的20日预测同步转负。此行为是现有规则的直接结果，不能解释为已验证的抄底能力。

事实证据见 `docs/close-review-2026-10-22.md`及`evidence/2026-10-22-close/`。禁止同日重买或冷静期仍应作为独立研究，不能事后改写此次账本或把条件归因当完整策略回测。

## 5. 回测、升级与样本外证据

`Analysis.evaluate`（234行起）是独立区间研究：2025等年份用前一年成熟截止模型，2026按前月成熟标签滚动。它使用研究指数及独立区间费用口径，不等于持续Paper账户。`scripts/executable-research.js:11`先截训练历史至2024-12-31，之后用共享Paper检验2025-01-02至2026-09-30。

这些历史年份已被查看，六ETF又是事后选定的存续标的池，存在幸存者/选择限制，不能称新的盲测。日线开收盘回放缺少历史盘口、停牌细节与盘中极端值，模型预测精度也不能直接推出可成交盈利优势。

已保存低仓位历史探索：12.5%模型候选累计约+8.09%、观测日线回撤约1.706%，仅8次完整退出、21个固定20日区间中9个为正；不是70%概率证明。25%模型候选虽累计为正，2026分年变化为负，未通过已登记风险筛选。见 `evidence/2026-10-20-capital-preservation/comparison.json`及`account-block-evidence.json`。

真实5万元账户截至10/22累计亏515.4676元，全期最高观测峰谷回撤604.4593元；同风险固定三ETF对照亏405.5457元。该时段候选未优于对照，风险要求未通过，也尚未完成多个独立20日周期。原1100、小仓和5万元收益不得相加、拼接或互作同一模型证据。

`Analysis.updateChampion`（390—407行）有候选筛选算法：旧模型截止之后的成熟时间窗口、至少60验证样本、MAE至少改善2%、方向准确率不下降超过2个百分点；但这不是扣费收益/风险/执行晋级门槛。UI已另行禁止自动部署，当前没有经完整未来验证证明可自动晋级为实投系统的证据。

## 6. 长期能力与尚缺部分

API允许horizon在1—120之间，只表示参数和标签生成能力，不代表已经训练、校准或验证短期全部周期，更不代表12个月预测能力。现有运行权重只有20交易日模型，1—12个月长期模型、长期样本外优势与可靠70%盈利概率均未建立。

后续研发应明确区分：完整、同规则、扣费连续回放；滚动样本外评估；与简单对照和现金比较；市场状态分层与数据覆盖审计；前瞻冻结晋级；以及长期运行队列和资源调度。新建队列或显示研发进度本身不等于这些能力已经接通。训练与策略研究必须保留失败、来源、时间边界和旧版本，不以事后盈利结果改写冻结交易。
