# 免费数据与20交易日验证升级

用户要求提高股票预测系统质量，确认继续使用免费来源，主要持有几周到一个月。当前初始模型不是大语言模型；2026截至9月30日方向42.93%，一直预测上涨42.89%，MAE也未胜过历史均值。这些结果不支持作为可靠实盘推荐。

本轮在既有数据分析和持续验证范围内补齐证据，不承诺提高收益或达到指定胜率：
- 同一时间切分的零收益、一直上涨、训练均值基准与模型并列；显示未经前瞻验证。
- 逐次固定20日预测的实际发布时间、参数输入和模型快照。软件不覆盖同一标的/信号日的最早记录。到期用实际后续交易日评分；发布晚于计划入场的记录排除。仅评价价格预测，不声称实际成交。
- 新闻继续展示与保留首次观察时间；增加选定公司的公开公告标题和来源。
- 明确新闻关键词不是大模型分析，初始模型未使用新闻、财报因子。免费轮询不是交易所无延时推送。
- EXE更新为验证增强版，保留本机既有模型/缓存，新增记录使用独立键，不清除用户数据。

验证：基准手算、首次记录不可覆盖、真实发布时间边界、过期信号排除、成熟标签结算和未来扰动不重写历史评分；实际Windows宿主联网、页面与旧功能回归。

用户随后明确要求模拟投资、2023抽样和实际一小时监测：
- `paper-engine.js`独立虚拟10万元账户，冻结选择/模型/报价，100股整手（科创板至少200股）、买入滑点0.1%、佣金0.03%且最低5元；只持有和按源报价估值，不模拟A股日内卖出，不连接券商。单次浮动收益不判为20日预测准确率。
- 模型页可联网同步后建立模型实验组合，个股详情可自行选定。忙碌、同步失败或所选历史未成功更新至共同日期时不建立新持仓；旧组合最多归档10组。建立成功开启自动更新。
- `historical-paper-replay.js`固定种子20231019和alpha0.1，8个不重叠2023窗口；决策快照先写入再单独评分，不能用2024参数选择回填2023。缺少未来退出价格时未结算，不变成事后现金。
- `live-paper-monitor.js`从2026-10-19 11:07:54至12:07:54（中国时间）计划连续采集一小时，保留初始模型实验组合与ETF/现金对照。外部本项目监测进程独立于用户账户，不写证券App。
