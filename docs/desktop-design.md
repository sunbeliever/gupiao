# Windows 桌面版

用户要求改为可双击打开的EXE，沿用已确认的分析、参数、行情、新闻和2025/2026检验范围。复用assets中的权威实现，不复制或重写预测引擎。

- 单个x64 .NET Framework EXE内置界面、真实初始数据、WebView2 SDK依赖；系统现有WebView2运行时负责独立桌面窗口。
- 初次运行释放到LocalAppData/TechScopeDesktop，用户数据单独保存，后续替换EXE保留缓存和模型。验证模式使用工作区内独立目录。
- 与安卓相同的Native接口由Windows宿主提供。网络限制为既有腾讯/东方财富HTTPS域名；阻止界面导航到外站，新闻用系统浏览器打开。
- 运行期间前台刷新行情；允许自动更新时，窗口最小化也由宿主定时采集。关闭软件即停止更新，不新增开机任务或系统服务。
- 通过单元行为测试、现有模型回归以及实际EXE内WebView2启动/桥/行情/新闻/缓存/页面回测检查，再交付exe与备用zip。
