## 软件当前行为

- 19只科技股票/ETF的价格、成交量/额、换手、PE/PB、均线、RSI、动量、波动与回撤；ETF不套用单家公司估值。
- 日线按交易所日历核查应完成日期，拒绝单只过期及全池共同落后。免费源连接失败时显示缓存和来源时刻。
- 全额命名方案以1万元配置最多3只合格科技ETF，保留整手/费用余款；小额学习方案独立保留。
- 30分钟工程观察与投资账户分离；观察结束后继续估值、跨日持有和请求合法退出，不重置本金或亏损。
- 策略、模型、数据、规则、费用和资金限制均有指纹；明确T+1、拒单、过期价和退出失败。
- 默认最低5元佣金为假设，开户前可按合同配置。排名、模拟成交、持续回放和对照使用同版费用。
- 同步不自动更换模型；手动训练只生成研究候选。新闻只有带来源和首次接收时间的标题字面事实/风险，尚未进入预测。
