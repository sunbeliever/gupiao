# 科技观察 · 股票数据分析

科技 A 股和科技 ETF 的中文数据分析工具。Windows 1.5全额资金研究版：双击 `dist/科技观察-全额资金研究版.exe`，免安装，界面和初始模型均已内置。[Windows使用说明](docs/windows-use.md)。新模拟以全部1万元配置1至3只合格标的，旧500元实验保留。新增完整资金历史研究、扣费盈利概率校准、已核实基金拆分分红账务。历史趋势候选有正收益，但70%单笔盈利概率未通过，当前不发出实盘买入推荐；未训练或接入大语言模型。原24轮半小时亏损不删除，参见[自动验证记录](docs/automatic-validation.md)。

下文保留安卓旧版说明；APK在 `dist/TechScope.apk`，Android 6.0及以上、系统WebView需保持更新。无需注册或提供证券账户。

## 功能
- 19只当前人工选择的科技股票/ETF研究池，可按板块、品种和参数比较。
- 腾讯公开行情每30秒刷新，显示数据源时间；未复权红涨绿跌K线及均线。
- 价格、涨跌、成交量/额、换手率、PE/PB；ETF估值指标显示不适用。
- MA5/20/60、RSI、动量、波动、回撤、量比；预测因子贡献、历史误差区间和风险。
- 科技新闻标题、来源、时间及原文链接；行业指数走势。标题关键词情绪只作观察。
- 初始岭回归模型；2025冻结检验、2026逐月滚动检验和候选版本比较。
- Windows 1.2提供同标签简单基准对照、公司公告、首次预测与模型输入快照及到期评分。日记独立于历史回测，排除开盘后迟发记录。
- 私有缓存支持离线查看。Android后台任务周期约30分钟，系统省电/强制停止可能延迟；打开应用后同步历史并评估新模型。

## 模型口径
预测目标是下一交易日开盘至21个交易日后的开盘的20日价格收益，非保证收益。后复权日线用于比例因子和建模，未复权日线用于展示。训练排除结果尚未发生的标签；当前报价、PE/PB和最新新闻不回填历史。更新模型必须通过独立于拟合样本的历史比较，记录接受或拒绝原因。持续训练不保证持续改善。

研究池是当前选定标的，存在幸存者偏差。回测为日线教学模拟，不能证明涨跌停排队成交、停牌卖出、税费、最小佣金、真实股数和分红现金都已完整模拟。费率默认每边0.15%的近似综合费用，不应直接当作个人实际费用。请查看回测页中当次报告说明。2026报告只覆盖真实已完成数据日期，不代表全年收益。初始版本展示实际验证结果，即使误差较大或策略落后也不会隐藏。

## 新闻与联网
应用不包含付费新闻全文，提供公开标题和原始链接。联网观察的标题会积累到私有缓存，最多保存90天/2500条并记录首次观察时间，便于后续分析；初始模型不使用新闻因子。新闻搜索只有有限最近结果，不具备完整历史新闻库；关键词统计不能理解所有语境，未作为历史训练因子。数据源接口可能改变或限流；连接失败显示缓存，时间戳不更新为假实时。

数据请求仅允许腾讯和东方财富指定HTTPS域名；数据与模型保存在应用私有目录，不上传个人账户或交易信息。后台设置可以关闭，系统“强制停止”后后台调度暂停，重新打开应用恢复。

## 安装与使用
将 `dist/TechScope.apk` 传到安卓手机并点击安装，在系统提示时为此次安装来源开启安装应用权限。打开“科技观察”，先使用内置初始数据，联网更新。观察页点选标的查看参数，回测页切换2025/2026，模型页查看训练记录。

## 验证范围

已在桌面浏览器验证手机宽度界面、离线和联网数据桥、搜索/切换/模型与回测按钮/设置保存；已执行Java网络与中文解码检查、预测时间边界测试以及APK结构和签名检查。尚未在安卓真机或安卓模拟器安装运行，系统WebView差异与后台调度行为需实际手机验证。

## 本地重建
`scripts/build-apk.py --bootstrap` 获取开放源码构建依赖；`scripts/build-apk.py` 编译、签名；`scripts/verify-apk.py dist/TechScope.apk` 验证结构。构建无需安装Android SDK或接受新的SDK许可。依赖许可证保存在 `tools/DEPENDENCY-LICENSES.md`。

市场解析与模型测试：`node --test tests/market.test.js tests/analysis.test.js`。真实数据准备：`node scripts/prepare-seed.js`，初始模型导出由 `scripts/finalize-seed.js` 完成。

签名密钥和密码文件仅在 `tools/` 本地保留，必须自行备份用于后续升级同一应用，禁止发布或打入APK。本项目不连接券商、不下单。
